# Equipped Attachment Model Reference

The first model pass is intentionally blocky and low-resolution so it fits Minecraft's player model. Every attachment is a separately named model child in `AttachmentModel`, which means one item can be resized or repositioned without changing saved armor NBT or the other attachments.

## Useful Review Views

For later adjustment screenshots, use third person from the front, back and side while standing, walking and crouching. Wings, tails and footwear are easiest to judge from the back and side. Masks and horns are easiest to judge without a bulky helmet first, then once more with the intended armor equipped to check clipping.
